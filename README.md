# stackshanicezwp-notes

Site reliability engineer @HashiCorp

处理日常小任务的工具

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。

## 备注

就是给自己省点事，没做太多抽象。

## 安装

```bash
git clone https://github.com/USER/stackshanicezwp-notes.git
cd stackshanicezwp-notes
chmod +x run.sh
```
